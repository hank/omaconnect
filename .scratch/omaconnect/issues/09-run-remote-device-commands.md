# 09 — Run Remote Device Commands

**What to build:** Users can inspect commands configured on the selected phone and execute one remotely from the popover.

**Blocked by:** 02 — Discover and Select Mobile Devices.

**Status:** completed

- [x] Opening or refreshing the active device loads its configured command list.
- [x] Command keys and human-readable labels are parsed into clearly labeled interactive controls.
- [x] Executing a command shows in-progress, success, and failure feedback.
- [x] Empty, malformed, or unavailable command lists have an understandable empty/error state.
- [x] Commands cannot execute against a stale or disconnected active device.
