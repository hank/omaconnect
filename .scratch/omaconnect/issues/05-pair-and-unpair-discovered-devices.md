# 05 — Pair and Unpair Discovered Devices

**What to build:** Users can understand whether a discovered device is paired, initiate the supported pairing flow, and explicitly remove a pairing.

**Blocked by:** 02 — Discover and Select Mobile Devices.

**Status:** completed

- [x] Unpaired devices are visibly distinct from paired devices.
- [x] A user can initiate pairing and see pending, accepted, rejected, and failed outcomes.
- [x] An active pairing request is represented without blocking unrelated device viewing.
- [x] A user can explicitly unpair a device and sees confirmation before the destructive action.
- [x] Pairing changes update device availability and controls without requiring a restart.
