# 02 — Discover and Select Mobile Devices

**What to build:** Users can open OmaConnect from the topbar, see reachable paired mobile devices, and select one device in a usable popover.

**Blocked by:** 01 — Establish a Runnable, Testable Plugin Shell.

**Status:** completed

- [x] The topbar item shows connection status and the number of reachable devices.
- [x] The popover lists device names and distinguishes the active device.
- [x] Selecting a device updates the active device card without blocking the shell.
- [x] Zero devices, no reachable devices, and a device-discovery failure each have clear UI states.
- [x] Interactive controls use the established hover, pressed, focus, and glassmorphic styling.
